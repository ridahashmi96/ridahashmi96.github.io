# Q+U website

Static site for Q+U, served by GitHub Pages at https://qplusu.github.io/.

Direction from harmoniqs.ai: a full-viewport hero on an animated canvas, a floating pill nav with a light/dark toggle that follows the time of day, tight display type and lots of air. The hero canvas (`src/radar.js`) is a sequencing disc: a sweep moves round a field of systems in schedule order, flipping each from quantum-vulnerable to post-quantum, skipping a quarter-close freeze, while the exposure figure falls. The earlier particle wave is in git history (commit 37facc9). No build step: edit `index.html`, `src/styles.css` and `src/radar.js`. Append `?theme=dark` or `?theme=light` to force a theme.

See `BACKLOG.md` for open work and `PEER_REVIEW.md` for the current review.
